# Captain Busara – boat tours in Kendwa, Zanzibar

Website of Captain Busara: [captainbusara.com](https://captainbusara.com) (English and Polish).

Static site hosted on GitHub Pages. Pages are generated from `tools/content.py` by `tools/build.py` (Python 3, no dependencies):

```bash
python3 tools/build.py
```
